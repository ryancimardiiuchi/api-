# Security Policy

## Supported Versions

As versões atualmente mantidas do projeto recebem correções de segurança quando necessário.

| Version | Supported |
| ------- | --------- |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability

Se você encontrar uma vulnerabilidade de segurança neste projeto, pedimos que não a divulgue publicamente em uma Issue do GitHub.

Entre em contato diretamente pelo e-mail:

**ryancimardiiuchi@gmail.com**

Ao relatar uma vulnerabilidade, se possível, inclua:

- Uma descrição do problema;
- Passos para reproduzir a vulnerabilidade;
- O impacto potencial;
- Screenshots ou exemplos, se necessário;
- Qualquer informação que possa ajudar na correção.

### O que esperar

Após receber o relatório, o problema será analisado e, quando possível, você receberá uma resposta sobre o status da vulnerabilidade.

Caso a vulnerabilidade seja confirmada, serão tomadas medidas para corrigi-la e uma atualização poderá ser publicada no projeto.

Agradecemos a todos que contribuem para manter este projeto mais seguro.
